# GitHub Upload Checklist

Use this checklist after reviewing the artifact locally.

## 1. Run the local artifact check

```bash
bash scripts/check_artifact.sh
```

The check compiles Python files, removes generated bytecode, and scans for common private paths or author-identifying strings.

## 2. Create a public GitHub repository

Recommended repository name:

```text
dirbridge-artifact
```

Keep it public and accessible without login before submitting the CMT supplemental material URL.

## 3. Initialize and push

```bash
git init
git add .
git status
git commit -m "Prepare DirBridge artifact"
git branch -M main
git remote add origin https://github.com/<account>/dirbridge-artifact.git
git push -u origin main
```

## 4. CMT URL

Use the public repository URL:

```text
https://github.com/<account>/dirbridge-artifact
```

If CMT provides a description box, use:

```text
The supplemental material is provided as a public GitHub repository containing the implementation of DirBridge and the selected baselines used in the paper (FedBuff, CA2FL, MA-Light, CASA, FADAS, and FedASMU), scripts for reproducing the main Dir-Skew and FedScale experiments, result summarization utilities, configuration files, and a quick smoke test for environment verification.
```

## 5. Before final submission

- Confirm the repository is public.
- Open the URL in a private/incognito browser window.
- Confirm README renders correctly.
- Confirm `scripts/check_artifact.sh` passes after clone.
- Confirm no raw datasets, generated logs, paper source, private server paths, or author-identifying metadata are included.
